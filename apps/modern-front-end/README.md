# Développement front-end moderne

Deck de cours [Slidev](https://sli.dev) basé sur le thème partagé
[`@alexischarp/slides-theme`](../../packages/theme).

```bash
# Depuis la racine du monorepo
pnpm --filter @alexischarp/slides-modern-front-end dev      # ouvre le deck
pnpm --filter @alexischarp/slides-modern-front-end build    # build statique
pnpm --filter @alexischarp/slides-modern-front-end export   # export PDF
```

Le contenu vit dans [`slides.md`](./slides.md). Layouts disponibles : `intro`,
`section`, `default` — voir le README du thème pour le détail.
